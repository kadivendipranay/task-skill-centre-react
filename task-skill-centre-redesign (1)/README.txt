Use:
1. Back up your existing src/App.js and src/styles/global.css.
2. Copy these files into the same paths in your project.
3. Run npm run dev and check the site.
4. Run npm run build before pushing to GitHub and redeploying.

Important: The registration form saves details only in the visitor's browser for this demo. It does not notify the training centre. Connect a backend or form service before collecting real registrations.
